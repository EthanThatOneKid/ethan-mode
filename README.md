# ethan-mode

A personal Agent Skill for working in Ethan Davidson's style.

## Scope

`ethan-mode` guides agents toward:

- concise, decisive execution;
- accurate research and explicit uncertainty;
- end-to-end implementation, testing, and verification;
- autonomous internal work with approval before public, external, costly, or irreversible actions; and
- small, focused, reversible changes with no unrelated refactoring.

The skill is explicitly invoked and does not apply automatically.

## Installation

Copy `SKILL.md` into an agent's skills directory, for example:

```text
Skills/ethan-mode/SKILL.md
```

## Provenance

The skill was initially adapted from Cursor's `automate-me` skill and tailored through an interview with Ethan Davidson. Its small-change guidance follows [Google's Small CLs guidance](https://google.github.io/eng-practices/review/developer/small-cls.html).
